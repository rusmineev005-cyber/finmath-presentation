# Презентация: Финансовая математика

## Описание проекта
Веб-презентация на тему "Основы финансовой математики", содержащая 22 слайда с основными понятиями, формулами и примерами.

## Структура проекта

## Содержание презентации
1. Тема и содержание
2. Введение в финансовую математику
3. Простые проценты
4. Сложные проценты
5. Сравнение видов процентов
6. Дисконтирование
7. Приведенная стоимость
8. Номинальная и эффективная ставка
9. Аннуитеты
10. Виды аннуитетов
11. Расчет аннуитетных платежей
12. Кредитные расчеты
13. Ипотечный кредит
14. Инвестиционные показатели
15. NPV (чистая приведенная стоимость)
16. IRR (внутренняя норма доходности)
17. Срок окупаемости
18. Индекс прибыльности
19. Финансовые риски
20. Учет инфляции
21. Практические примеры
22. Выводы и заключение

## Как использовать
1. Откройте файл `index.html` в любом современном браузере
2. Для навигации используйте:
   - Кнопки "Назад" и "Вперед"
   - Стрелки ← → на клавиатуре
   - PageUp/PageDown
   - Home/End для перехода к началу/концу

## Особенности
- **22 слайда** с полным охватом темы
- **Правильная навигация** — не пропускает слайды
- **Простой дизайн** — выглядит как студенческая работа
- **Формулы и примеры** — на каждом слайде
- **Адаптивный дизайн** — работает на компьютерах и телефонах
- **Не требует интернета** — все файлы локально

## Технические детали
- Чистый HTML, CSS и JavaScript
- Без использования библиотек
- Кросс-браузерная совместимость
- Простая структура кода

## Для преподавателя
Презентация демонстрирует понимание основных концепций финансовой математики:
- Временной стоимости денег
- Простых и сложных процентов
- Дисконтирования и приведенной стоимости
- Инвестиционных показателей (NPV, IRR, PP, PI)
- Финансовых рисков и учета инфляции


Все формулы сопровождаются практическими примерами расчетов.

# Финансовая математика - Вариант №1

## Описание проекта
Презентация по финансовой математике (27 слайдов) для варианта №1.

## 📊 Структура презентации
1. Титульный слайд
2. Определение финансовой математики (1 балл)
3. Простые проценты: наращение (2 балла)
4. Простые проценты: дисконтирование (2 балла)
5. Сложные проценты: наращение (2 балла)
6. Сложные проценты: дисконтирование (2 балла)
7. Проект 1: Банковский депозит (2 балла)
8. Проект 2: Кредитный калькулятор (2 балла)
9. Проект 3: Инвестиционный анализ (2 балла)
10-21. 12 примеров расчета (по 2 балла)
22. Таблица "Приведенные номера дней в год" (17 баллов)
23. Калькулятор кредита на JavaScript
24. Результат 1: Ипотека
25. Результат 2: Автокредит
26. Результат 3: Образование
27. Заключение

## 🚀 Как использовать
1. Откройте `index.html` в браузере
2. Для навигации используйте:
   - Кнопки "Назад" и "Вперед"
   - Стрелки ← → на клавиатуре
   - PageUp/PageDown
   - Home/End

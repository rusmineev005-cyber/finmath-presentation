Определение финансовой математики

Основные задачи:

  • Расчет процентов по вкладам и кредитам
  • Оценка инвестиционных проектов

Применение:

  • Инвестиционный анализ
  • Страхование
  • Корпоративные финансы

Простые проценты: Наращение

Формула наращения по простым процентам:

S = P × (1 + i × n)

Обозначения:

  • S — будущая сумма
  • P — первоначальная сумма
  • i — процентная ставка
  • n — время в годах
Пример: Вклад 50 000 руб. под 8% годовых на 3 года.
S = 50 000 × (1 + 0.08 × 3) = 62 000.00 руб.

Простые проценты: Дисконтирование

Формула дисконтирования по простым процентам:

P = S / (1 + i × n)

Обозначения:

  • P — текущая стоимость
  • S — будущая сумма
  • i — учетная ставка
  • n — время до платежа
Пример: Вексель 100 000 руб. через 180 дней, ставка 10%.
P = 100 000 / (1 + 0.10 × 180/360) = 95 238.10 руб.

Сложные проценты: Наращение

Формула наращения по сложным процентам:

S = P × (1 + i)n

Обозначения:

  • S — будущая сумма с капитализацией
  • P — первоначальная сумма
  • i — процентная ставка за период
  • n — количество периодов
Пример: Вклад 50 000 руб. под 8% годовых на 3 года.
S = 50 000 × (1.08)3 = 62 985.60 руб.

Сложные проценты: Дисконтирование

Формула дисконтирования по сложным процентам:

P = S / (1 + i)n

Обозначения:

  • P — приведенная стоимость
  • S — будущая сумма
  • i — ставка дисконтирования
  • n — количество периодов
Пример: Получить 200 000 руб. через 3 года под 12%.
P = 200 000 / (1.12)3 = 142 356.05 руб.

Калькулятор для расчета доходности банковского вклада.

  • Расчет простых и сложных процентов

  • Расчет эффективной процентной ставки

  • Сравнение разных предложений банков
Цель: Помочь выбрать выгодный вариант вклада.
